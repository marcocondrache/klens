# AGENTS.md

## Commits

- Always use [Conventional Commits](https://www.conventionalcommits.org/) (e.g. `feat(web): ...`, `fix: ...`, `refactor(app): ...`).

## Pull requests

- Keep the description short and direct: a single phrase stating why the change is needed and briefly what it does.

## Attribution

- Never add attribution (e.g. `Co-Authored-By`, "Generated with ..." footers, session links) to commits or PR descriptions.
