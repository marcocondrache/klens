---
title: klens
description: A web UI and MCP server for Kafka, served by one Rust binary.
---

klens shows the topics, records, consumer groups, brokers, schemas, ACLs, quotas, and SCRAM users of one or more Kafka clusters. It is one binary that serves the UI, a JSON API, and, when you turn it on, tools for AI agents over MCP. Each cluster must run Apache Kafka 3.9 or later.

klens reads each cluster in the background into memory, and every page reads that copy. A page costs Kafka nothing, however many people have it open. Only record reads, live tails, and changes go to Kafka when someone asks.

## What you can do

- Browse topics with their partitions, sizes, produce rates, retention, and configs.
- Search the records of a topic by text, partition, and time, decode Avro, JSON Schema, and Protobuf values, and download the matches as NDJSON.
- Follow a topic live.
- Watch consumer groups and their lag, and reset or delete their offsets.
- Read and register schemas, and set compatibility levels.
- Manage ACL bindings, SCRAM users, client quotas, and broker configs.
- Hide card numbers, emails, and other private fields in records for every reader.
- Sign users in with OpenID Connect, and give each group its own privileges on each cluster.
- Let AI agents read the same data through MCP, under a ceiling you set.

klens changes nothing on a cluster until you mark it `writable` and grant the privilege for the change.
